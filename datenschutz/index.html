2. Allgemeine Hinweise zur Datenverarbeitung

Personenbezogene Daten werden nur in dem Umfang verarbeitet, der für die Bereitstellung dieser Website, die Bearbeitung von Anfragen sowie für technisch notwendige Abläufe erforderlich ist.

3. Kontaktformular

Wenn du das Kontaktformular nutzt, werden die von dir eingegebenen Daten ausschließlich zur Bearbeitung deiner Anfrage sowie für mögliche Rückfragen verarbeitet.

4. Server-Logfiles / Hosting

Beim Aufruf der Website verarbeitet der Hosting-Anbieter technisch erforderliche Verbindungsdaten in Server-Logfiles. Dazu können insbesondere IP-Adresse, Zeitpunkt des Zugriffs, aufgerufene Seiten sowie technische Informationen zum verwendeten Browser gehören.

5. Externe Dienste

Sofern auf dieser Website externe Dienste, eingebettete Inhalte, Karten, Videos, Schriftarten oder Analysetools eingesetzt werden, erfolgt deren Nutzung im Rahmen der jeweils geltenden datenschutzrechtlichen Vorgaben.

6. Rechte betroffener Personen

  • Auskunft über gespeicherte personenbezogene Daten
  • Berichtigung unrichtiger Daten
  • Löschung oder Einschränkung der Verarbeitung
  • Widerspruch gegen bestimmte Verarbeitungen
  • Datenübertragbarkeit, soweit anwendbar
  • Beschwerde bei einer zuständigen Aufsichtsbehörde
